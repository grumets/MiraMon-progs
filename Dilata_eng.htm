• Dilata: Dilation of pixels of a selected value in raster files

Performs the image processing operation and mathematical morphology known as dilation, which takes a value and replicates it in the geometric immediate surroundings.

The syntax section of this document specifies the different directions that the dilation process can be. Rasters subjected to this module are typically masks, binary or not, where we want to dilate all values other than the background value (NoData), or thematic maps with different values in the legend previously rasterized (e.g. lines) that we want to dilate (in these cases, the program will dilate these structures, respecting the rest of the map).

The dilation can also be used as an approximation to a directional or radial buffer with a pixel size (or pixel by square root of 2 for expansion on all neighbors), to apply around raster areas or rasterized linear elements. The richness of expansion types that this module supports makes it complementary to the TiraVec and BufDist modules.

The process, which supports both files with integer and real values, also acts on the image borders.

More information: https://en.wikipedia.org/wiki/Dilation_(morphology)

Syntax:

  • Dilata InputFile OutputFile ValueDilate TypeDilation

Parameters:

  • InputFile (Raster file to dilate - Input parameter): Raster file with one o more values that we want to dilate.
  • OutputFile (Output file - Output parameter): Output file from the dilation of the requested value.
  • ValueDilate (Value to dilate - Input parameter): Value to be dilated. If you want to dilate any value other than NoData, specify X.
  • TypeDilation (Type of dilation - Input parameter): Type of dilation:
    • 1 N-S
    • 2 E-W
    • 3 On cross of Malta (N-S and E-W)
    • 4 On cross of Malta and diagonally (all the neighbors)
    • 5 Down and to the left (S and W)
    • 6 Down and to the left, and both (S, W and SW)
