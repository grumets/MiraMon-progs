• GPXMM: Importación y exportación de archivos GPX a archivos estructurados de MiraMon

Este módulo sirve para convertir un archivo en formato GPX (GPS eXchange Format) al formato vectorial estructurado de MiraMon (PNT, ARC/NOD) y viceversa.

    Importación: Conversión de un archivo en formato GPX (GPS eXchange Format) al formato vectorial estructurado de MiraMon (PNT, ARC/NOD).

Un archivo GPX es un formato basado en un esquema XML que pensado para la compartición de datos de receptores GNSS (popularmente conocidos como GPS) entre diferentes aplicaciones. Este archivo puede contener 1 o más puntos de interés georreferenciados (waypoints), trayectos (tracks) o rutas (routes). En esta página, se puede consultar información más detallada de la estructura que debe tener un archivo GPX y de las definiciones para cada uno de estos elementos.

En la importación de un archivo GPX, los archivos de salida dependerán del tipo de datos existentes en el archivo origen. Si contiene trayectos, se creará un archivo vectorial estructurado de arcos (.arc). Si el archivo GPX contiene puntos, se creará un archivo vectorial estructurado de puntos (.pnt). Si en el fichero GPX hay rutas (conjuntos de puntos que definen un itinerario que se pretende seguir), también se creará un archivo vectorial estructurado de arcos que los une formando un posible trayecto entre ellos. En cualquiera de los casos, también se creará un fichero Mapa de MiraMon en el cual se podrán ver todos los datos importados. En relación a los datos alfanuméricos, se guardan todos los atributos definidos tanto para los elementos de tipo punto como para los elementos de tipo arc que contenga el archivo GPX. Además, en el caso de los trayectos, también se guarda el tiempo inicial y final del trayecto (timestamp) en Tiempo Universal Coordinado (UTC) y la mínima y máxima altitud elipsoidal.

En la exportación de un fichero en formato PNT y/o ARC/NOD a un archivo GPX, y debido a las limitaciones del formato GPS, el programa permite guardar los atributos de un solo campo de la tabla asociada al archivo PNT y/o ARC dónde se guardará en el atributo <name> de los puntos georreferenciados y/o trayectos del fichero destino. En el caso que no se asigne ningún campo, por defecto, se llenará con el nombre del archivo seguido del identificador gráfico del punto o del arco correspondiente.

Según las especificaciones del formato GPX, las coordenadas de los datos de archivo son relativas al datum WGS84 y la unidad de medida es el metro. Sin embargo, esta aplicación permite la reproyección de los datos del archivo GPX a otro sistema de referencia durante la importación. Para tener más información sobre los sistemas de referencia, se puede consultar el documento Sistemas de referencia horizontal en MiraMon. Tablas y ficheros de geodesia para     más información.

Sintaxis:

  • GPXMM 1 FitxerGPX FitxerMMM [/SIST_DEST] [/ELIP]
  • GPXMM 2 FitxerPNToARC FitxerGPX [/NAME_PNT] [/DESC_PNT] [/NAME_ARC] [/DESC_ARC] [/ELIP]
  • GPXMM 2 FitxerPNT FitxerARC FitxerGPX [/NAME_PNT] [/DESC_PNT] [/NAME_ARC] [/DESC_ARC] [/ELIP]

Opciones:

  • 1: Importación del formato GPX al formato MMM.
  • 2: Exportación del formato PNT y/o ARC/NOD al formato GPX.

Parámetros:

  • FitxerGPX (Archivo GPX - Parámetro de entrada): Es el archivo GPX a importar o exportar.
  • FitxerMMM (Archivo MMM - Parámetro de salida): Archivo de salida en formato MMM
  • FitxerPNToARC (Archivo PNT o archivo ARC - Parámetro de entrada): Es el archivo PNT o el archivo ARC/NOD a exportar a GPX
  • FitxerPNT (Archivo PNT - Parámetro de entrada): Es el archivo PNT a exportar a GPX
  • FitxerARC (Archivo ARC - Parámetro de entrada): Es el archivo ARC/NOD a exportar a GPX

Modificadores:

    /SIST_DEST= (Sistema de referencia de destino) Identificador del sistema de referencia del archivo destino en el caso de que se opte por reproyectar la salida. Si no se indica, se mantendrá el sistema de referencia indicado en el GPXMM. (Parámetro de entrada)
  • /NAME_PNT= (Nombre campo PNT para etiqueta Name) Indica el nombre del campo del PNT que hará de etiqueta Name [nombre del punto de interés] (si el archivo a exportar es un PNT). (Parámetro de entrada)
  • /DESC_PNT= (Nombre campo PNT para etiqueta Desc) Indica el nombre del campo del PNT que hará de etiqueta Desc [descripción del punto de interés] (si el archivo a exportar es un PNT). (Parámetro de entrada)
  • /NAME_ARC= (Nombre campo ARC para etiqueta Name) Indica el nombre del campo del ARC que hará de etiqueta Name [nombre del trayecto] (si el archivo a exportar es un ARC). (Parámetro de entrada)
  • /DESC_ARC= (Nombre campo ARC para etiqueta Desc) Indica el nombre del campo del ARC que hará de etiqueta Desc [descripción del trayecto] (si el archivo a exportar es un ARC). (Parámetro de entrada)
  • /ELIP (Altitud elipsoidal a altitud ortométrica) Asignar la altitud elipsoidal a la altitud ortométrica. (Parámetro de entrada)
