• GPXMM: Importing and exporting GPX files to structured MiraMon files

This module is used to convert a GPX format file (GPS eXchange Format) into MiraMon structured vector format (PNT, ARC/NOD) and viceversa.

    Import: Conversion from a GPX format file (GPS eXchange Format) to MiraMon structured vector format (PNT, ARC/NOD).
    Export from PNT format or ARC/NOD format to GPX format: Export from PNT or ARC/NOD format to GPX format.
    Export from PNT format and ARC/NOD format to GPX format: Export from PNT and ARC/NOD format to GPX format.

A GPX file is a format based on an XML scheme that is intended for data sharing from GNSS receivers (popularly known as GPS) between different applications. This file may contain 1 or more geo-referenced points of interest (waypoints), tracks or routes. More detailed information about the structure of a GPX file and the definitions for each of these types of elements can be consulted in this webpage.

In a GPX file importing, the output files will detach from the type of existing data in the input file. If it contains tracks, an arc structured vector file (.arc) will be created. If the GPX file contains points, a point structured vector file (.pnt) will be created. If the GPX file contains tracks (sets of points that define a route to be followed), a structured vector file of points will also be created for the georeferenced points and another structured vector file of arcs that joins them forming a possible trace between them. In any case, a MiraMon Map file will be created too where all the imported data can be seen. In relation with alphanumeric data, all the attributes are saved for both point-type and arc-type elements contained in the GPX file. Also, in the case of tracks, the initial and final time of the track (timestamp) will be saved in Universal Time Coordinated (UTC) and the minimum and maximum ellipsoidal altitude.

In exporting from PNT and/or ARC/NOD format file to a GPX file, and due to the limitations of the GPX format, the program allows to save the attributes of a single field of the table associated with the PNT and/or ARC/NOD file where it will be saved in the <name> attribute of the georeferenced points and/or tracks of the destination file. In case of not assigning any field, by default, the field will be filled with the name of the file followed by the graphical identifier of the corresponding point or arc.

According to the specification of GPX format, file data coordinates are relative to WGS84 datum and the measurement unit is meter. However, this application allows the reprojection from the GPX file data to another reference system during import. For more information about reference system, you can consult the file MiraMon horizontal reference systems. Geodesic tables and files for further information.

Syntax:

  • GPXMM 1 FitxerGPX FitxerMMM [/SIST_DEST] [/ELIP]
  • GPXMM 2 FitxerPNToARC FitxerGPX [/NAME_PNT] [/DESC_PNT] [/NAME_ARC] [/DESC_ARC] [/ELIP]
  • GPXMM 2 FitxerPNT FitxerARC FitxerGPX [/NAME_PNT] [/DESC_PNT] [/NAME_ARC] [/DESC_ARC] [/ELIP]

Options:

  • 1: Import from GPX format to MMM format.
  • 2: Export from PNT and/or ARC/NOD format to GPX format.

Parameters:

  • FitxerGPX (GPX file - Input parameter): GPX file to import or export
  • FitxerMMM (MMM file - Output parameter): Output file in MMM format
  • FitxerPNToARC (PNT file o ARC file - Input parameter): PNT or ARC/NOD file to export into a GPX
  • FitxerPNT (PNT file - Input parameter): PNT file to export into a GPX
  • FitxerARC (ARC file - Input parameter): ARC/NOD file to export into a GPX

Modifiers:

    /SIST_DEST= (Destination reference system) Reference system identifier of the destination file in case that a reprojection option is performed. If not indicated, it will maintain the reference system stated in the GPXMM. (Input parameter)
  • /NAME_PNT= (Name of PNT field for Name tag) Field name of the PNT that will perform as a Name tag [name of the point of interest] (if the file to export is a PNT). (Input parameter)
  • /DESC_PNT= (Name of PNT field for Desc tag) field name of the PNT that will perform as a Desc tag [description of the point of interest] (if the file to export is a PNT). (Input parameter)
  • /NAME_ARC= (Name of ARC field for Name tag) Field name of the ARC that will perform as a Name tag [name of the track] (if the file to export is an ARC). (Input parameter)
  • /DESC_ARC= (Name of ARC field for Desc tag) field name of the ARC that will perform as a Desc tag [description of the track] (if the file to export is an ARC). (Input parameter)
  • /ELIP (Ellipsoidal altitude to orthometric altitude) Assign the ellipsoidal altitude to the orthometric altitude. (Input parameter)
