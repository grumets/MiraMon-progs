• TST: Earth Surface Temperature computation

This module is used to calculate the temperature of Earth surface according to emissivity data, steam, and a thermal band. Air temperature data could also be added.

There are two options:

    Steam: This option is used to calculate the temperature of the Earth's surface from steam data.
    Steam and air temperature: This option is used to calculate the temperature of the Earth's surface from steam and air temperature data.

One of the available atmospheric bases is needed to be chosen: TIGR-1, TIGR-2, TIGR-3 and STD. Also, the sensor of the thermal band. Users can choose between reading the sensor from metadata or choosing one of the available sensors: Landsat-4 (MSS), Landsat-5 (TM), Landsat-7 (ETM+).

The red band, the infrared band and the mask (in the case it is added) must have the same field, resolution and reference system for a correct functioning in the application.

Syntax:

  • TST 0 Thermal Emissivity Steam TST BD_Atmos Sensor
  • TST 1 Thermal Emissivity Steam TempAire TST BD_Atmos Sensor

Options:

  • 0: Calculation of the TST from steam data.
  • 1: Calculation of the TST from steam and air temperature data.

Parameters:

  • Thermal (Thermal - Input parameter): Input thermal band file.
  • Emissivity (Emissivity - Input parameter): Input emissivity data file.
  • Steam (Steam - Input parameter): Input stream data file.
  • TST (Terrestrial Surface Temperature - Output parameter): Output file of the result of the calculation of the temperature of the Earth's surface.
  • BD_Atmos (Input parameter): Atmospheric database. The available values are: "TIGR-1", "TIGR-2", "TIGR-3" or "STD".
  • Sensor (Input parameter): Thermal band sensor. The available values are:
    • 0 (get sensor from metadata)
    • 4 (for Landsat-4 MSS)
    • 5 (for Landsat-5 TM)
    • 7 (for Landsat-7 ETM+).
  • TempAire (Air Temperature - Input parameter): Input air temperature data file.

Modifiers:

    This module has no modifying parameters.

Example:

TST 0 D:\dades\b6.img D:\dades\emisiv.img D:\dades\vapor_agua.img D:\prova\TST.img TIGR-1 0
TST 0 D:\dades\b6.img D:\dades\emisiv.img D:\dades\vapor_agua.img D:\dades\temp_aire.img D:\prova\TST.img TIGR-1 0
