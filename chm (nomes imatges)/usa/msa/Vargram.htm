wVargram: Variogram representation and modeling

    Direct access to online help: Vargram

wVargram is the MiraMon tool that represents and models the semivariogram, a spatial pattern describing the relationship between semivariance and distance. Semivariance, which is half the variance, is a measure of the dispersion of a variable around its expected value and is calculated as the sum of the squared deviations from the mean. The semivariogram (or variogram, as it is often called, since the two concepts are essentially equivalent) makes it possible to analyze the spatial behavior of a property or variable within the study area. Its modeling is a key element in the process of geostatistical interpolation (kriging).

The main function of this module is to build and analyze the empirical variogram and model it by generating a fitted variogram as a possible sum of the supported elementary variogram models: nugget, spherical, quadratic, linear, Gaussian, and exponential. The variable to be modeled is specified as a field in the database associated with the structured point file (PNT), and the modeled variogram can be saved as an ASCII file in VAM.

The variogram construction process consists of two stages, organized into two tabs in the interface of wVargram.

In the first stage, the properties of the point sample are set, and the geometric and graphical parameters of the empirical variogram are defined:

First, the point file corresponding to the data sample to be analyzed must be specified. If necessary, a subset of the data can be selected, in which case only the selected points will be used in the process. The database field containing the variable to be represented and/or modeled must also be selected.

A file must be specified for the results report. This text file contains information about the source file, the geometric and graphical parameters, and a list of intervals with the number of point pairs belonging to each interval, along with the mean and semivariance assigned to that interval.

The geometric and graphical parameters to be defined are listed below. If necessary, the maximum distance between points can be calculated at any time using the "Calculate maximum" button:

  • Distance threshold: The maximum distance for variogram analysis, expressed in units of the horizontal reference system (HRS), typically meters. Point pairs separated by a distance greater than the specified threshold are excluded from the variogram analysis.
  • Number of intervals (lags): Specifies the number of groups into which the analysis range is divided. This determines the number of points plotted in the empirical variogram.
  • Interval width (lags): Specifies the width of each of the previously defined groups.

Multiples of the HRS units, such as km, can be used on the plot if the interval width is appropriate.

The distance threshold, number of intervals, and interval width are interrelated such that the distance threshold corresponds to the number of intervals multiplied by the interval width.

  • % cut: The percentage of the maximum distance between points represented by the distance threshold.
  • All directions: Indicates that the analysis is performed in all directions. If this option is not selected, the analysis is restricted to the vicinity of a single direction.
  • Azimuth and width: When analyzing possible anisotropy in the distribution, these parameters specify the central direction and the angular width of the surrounding sector, in degrees.

By default, the system performs calculations using 10 intervals and a cut of 50%. These default values can be restored at any time by clicking the corresponding button.
The parameter refresh button can also be used to see how a change in one parameter affects the others.

The final step of this first stage, once the adjustable parameters have been set, is to Generate the empirical variogram. The resulting plot displays one point for each interval, with distance on the horizontal axis and the semivariance of the point pairs assigned to the corresponding interval on the vertical axis. The specific mean and semivariance values can be obtained from the alphanumeric point database with much greater precision than can be read from the plot. Three levels of visualization are available:

  • Preview within the interface itself
  • Enlarged view in a separate window, accessed by clicking anywhere in the preview.
  • MiraMon graph opened in a new session using the Open graphic in MiraMon button:

In summary, one of the main objectives of this initial parameter setup is to generate the empirical variogram.

The main goal of the second stage is to generate the modeled variogram and determine the corresponding structural parameters of its spatial pattern. First, the elementary variogram models and their appropriate parameters are selected to form the composite fitted variogram. It is advisable to consult specialized references to understand some of the details of this structure. Two useful introductory references are:

    Oliver, M. A., Webster, R. (1990), "Kriging: a method of interpolation for geographical information systems". International Journal of Geographical Information Science, 4:3, 313 - 332

    Kitanidis P.K. (1997) Introduction to geostatistics: applications to hydrogeology. Cambridge University Press.

This second modeling stage produces the fitted or modeled variogram, which, if considered valid, will be used in the InterPNT module for interpolation using kriging.

The first part of the Modeling tab corresponds to the construction of the fitted variogram as the sum of some of the supported elementary variogram models: nugget, spherical, quadratic, linear, Gaussian, and exponential.

The resulting variogram parameter file is a VAM file that can be loaded from a file saved to disk or generated from scratch and saved at any time. The program also saves it when generating the fitted variogram.

The fitted variogram's graphic directory can be a temporary directory if the plot is only to be viewed, or a specific directory if the plot is to be saved to disk for future use.
