• GestTop: Management of MiraMon topological files

This module groups a set of tools and vector functionalities, mainly structured formats and topological procedures, but in some cases, also some aspects strictly non-topological. They are very specific procedures, that many times they already belong to some of the algorithms of the different modules of vectorial and topological treatment, but on some occasions, users could need them in an individual way. Different procedures are stated through different detailed options:

    TRUNCA_Z (1): Transforms a vector from 3D to 2D, by removing its Z component. In the current version it is not implemented for points, and it must be taken into account that for polygons it is referred to the arcs file.
    UNIR_OBJECTES_VEC (2): Joins objects from a VEC file of arcs or polygons that are connected, but without analyzing nor merging possible intersections; in this case, the LinArc module must be used.
    ENV_A_DBF (3): Writes the bounding of each object from an arcs or polygons file in 4 fields of the main table named MINX, MAXX, MINY, MAXY. It does not apply to point files; in this case, use PNTBD.
    ESTRUC_POLS (4): Structures topologically a polygon layer. Some MiraMon applications, like DGN_MM or DXFVec, generate layers that, due to efficiency reasons, they cannot have the polygons groups structured topologically. With this option, layers with this origin can be structured to, usually, use them as an entry of other applications that have this requisite. For further information about polygon groups and their structuration consult the Ciclar.

Syntax:

  • GestTop 1 Arc3D
  • GestTop 2 VectorDestí VectorOrigen Atribut [/N_DECIMALS]
  • GestTop 3 Vector
  • GestTop 4 FitxerPolDestí FitxerPolOrig [/AREA_MIN] [/AREA_PERI_MIN] [/NEXE_CRITERIS] [/FONDRE] [/ATRIB_ELIM]

Options:

  • 1: Transformation of a file from 3D to 2D.
  • 2: Union of VEC objects.
  • 3: Boundings of the elements of a topological vector.
  • 4: Polygon groups structuring.

Parameters:

  • Arc3D (Input parameter): 3D arc file to be transformed/transformed into 2D.
  • VectorDestí (Output Vector - Output parameter): Transformed vector.
  • VectorOrigen (Origin Vector - Input parameter): Vector on which the process is applied. If VectorDesti is the same as VectorOrigen, the transformation is done over the vector itself.
  • Atribut (Input parameter): Constant attribute of the VEC after the union of the available connections.
  • Vector (Input parameter): Vector file of which the boundaries of each object will be written in the XMIN, XMAX, YMIN, YMAX fields of the main table.
  • FitxerPolDestí (Output Polygon File - Output parameter): Structured polygons file.
  • FitxerPolOrig (Origin Polygon File - Input parameter): Original file of non-structured polygons.

Modifiers:

    /N_DECIMALS= (Number decimal figures) Number of decimal figures written in the coordinates of the output file. (Input parameter)
  • /AREA_MIN= (Minimum Area) Minimum area allowed for a polygon. (Input parameter)
  • /AREA_PERI_MIN= (Minimum Perimeter Area) Minimum allowed area/perimeter relation. (Input parameter)
  • /NEXE_CRITERIS= (Nexus criteria) In the case of indicating both criteria, eliminate the polygons meeting both conditions at the same time (AND), or the ones meeting only one of those (OR). Default value is AND. (Input parameter)
  • /FONDRE= (Melt) States which polygon is assigned to the space occupied by the micro-polygon that disappears. State POL_GRAN in order to assign the space to the biggest contiguous polygon of the area. Default value is FRONTERA_MES_LLARGA, meaning that the longest arc is erased from the micro-polygon that disappears. (Input parameter)
  • /ATRIB_ELIM= (Inherit attributes) The polygon absorbing the micro-polygon inherits its attributes if the value is 1. The value by default is 0, meaning that the attributes of micro-polygons are lost. (Input parameter)
