SubsTXT: Sustitución de textos dentro de un fichero

Este programa sustituye cadenas de texto dentro de ficheros de texto.

El fichero de salida es el mismo que el de entrada (se sobrescribe).

La sustitución es sensible a mayúsculas y minúsculas, pero se puede desactivar este comportamiento con /INSENSIBLE.

En esta versión el tamaño máximo del fichero son 2 Gbyte. Si se necesita que se soporte ficheros más grandes, puede escribirse a suport@miramon.uab.cat

Sintaxis:
SubsTXT Fichero "Cadena1" "Cadena2"
SubsTXT Fichero "Cadena1"

  • Fichero: Es el fichero con textos a sustituir.
  • Cadena1: Es la cadena de texto a buscar.
  • Cadena2: Si no hay /CADENA2_FITXER en la línea de comando, es la cadena de texto que sustituirá a Cadena1. Si no hay "Cadena2", se interpreta como una cadena vacía y se suprime el texto "Cadena1" del fichero.
  • /CADENA2_FICHER En caso de incluir este parámetro, indica que Cadena2 es un nombre de fichero que contiene la cadena a sustituir. Típicamente se utiliza para materializar una "inclusión" de un fichero dentro del 'Fichero' en el lugar donde esté la Cadena1.
  • /SOLO_TEXT= Fuerza a aplicar la sustitución sólo sobre la cadena de texto indicada (limitada a 2041 caracteres de longitud).
  • /ANSI El fichero de texto está escrito en ANSI-1252. Si no se indica, se supone OEM850. Este parámetro sólo es relevante para sustituir caracteres con códigos superiores al 127 (como letras acentuadas, etc).
  • /DIERESI_ES_COMETES Si Cadena1 y/o Cadena2 deben contener comillas es necesario escribir diéresis en su lugar y usar este parámetro. No debe usarse este parámetro si se debe escribir una diéresis solitaria que realmente sea una diéresis (no una diéresis sobre una vocal, como "Güell", donde no aplica).
  • /SEQ_ESCAPE Si Cadena1 y/o Cadena2 deben contener caracteres de escape (caracteres ANSI con códigos inferiores al número 32), se puede escribir la cadena de escape correspondiente al lenguaje C. Por ejemplo, para convertir retornos UNIX a retornos Windows es necesario usar SubsTXT Fichero "\n" "\r\n" /SEQ_ESCAPAMENT y para convertir tabuladores a espacios es necesario usar SubsTXT Fichero "\t" " " SEQ_ESCAPAMENT
  • /INSENSIBLE La sustitución aplica tanto a mayúsculas como a minúsculas. En esta versión no se reconoce la equivalencia en letras acentuadas (á no se considerará igual a Á); si se necesita esta funcionalidad, escriba a suport@miramon.uab.cat.

  • /OCUR= Permite indicar el número máximo de sustituciones que efectuará. Esto a menudo es útil para realizar la sustitución sólo en la primera ocurrencia, indicando un valor 1.
