SubsTXT: Substitution of texts within a file

This program replaces text strings within text files.

The output file is the same as the input file (overwritten).

Substitution is case sensitive, but this behavior can be turned off with /INSENSITIVE.

In this version the maximum file size is 2 Gbyte. In case of supporting larger files, write to suport@miramon.uab.cat

Syntax:
SubsTXT File "String1" "String2"
SubsTXT File "String1"

  • File: It is the file with texts to replace.
  • String1: It is the text string to search for.
  • String2: If there is no /STRING2_FILE in the command line, this is the text string that will replace String1. If "String2" is not present, it is interpreted as an empty string and the text "String1" is deleted from the file.
  • /STRING2_FILE If this parameter is included, it indicates that String2 is a file name containing the string to be replaced. It is typically used to materialize an "inclusion" of a file within 'File' at the location where String1 is.
  • /NAMES_TEXT= Forces the substitution to be applied only to the given text string (limited to 2041 characters in length).
  • /ANSI The text file is written in ANSI-1252. If not specified OEM850 is assumed. This parameter is only relevant for replacing characters with codes greater than 127 (such as accented letters, etc).
  • /DIERESI_ES_COMETES If String1 and/or String2 must contain quotation marks you must write umlauts instead and use this parameter. This parameter should not be used if a solitary umlaut is to be written that is actually a umlaut (not a umlaut over a vowel, as in "Güell", where it does not apply).
  • /SEQ_ESCAPEMENT If String1 and/or String2 must contain escape characters (ANSI characters with codes less than number 32), the corresponding C language escape string can be written. For example, to convert UNIX returns to Windows returns it must be used SubsTXT File "\n" "\r\n" /SEQ_ESCAPAMENT and to convert tabs to spaces it must be used SubsTXT File "\t" " " /SEQ_ESCAPAMENT
  • /INSENSITIVE Substitution applies to both upper and lower case. This version does not recognize equivalence in accented letters (à will not be considered equal to À); if this functionality is needed, write to suport@miramon.uab.cat.

  • /OCUR= Allows to indicate the maximum number of substitutions that will be made. This is often useful to make the substitution only on the first occurrence, indicating a value of 1.
