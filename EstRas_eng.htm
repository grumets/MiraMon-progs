• EstRas: Statistical data of a raster or a raster serie

This module calculates statistical data of raster images in which it is possible to choose between three options: The calculation of statistical data of a single raster (monoband or multiband), the calculation of an image with the result of the chosen statistical function in a raster serie and standardizing a raster (monoband or multiband).

For the calculation of statistical data of a single raster, the input file must be an IMG raster file and at least one of the available statistical functions must be selected (depending on the selected treatment of the data). The output file must be an INI file where the result of the different chosen statistical calculations will be written. This option allows doing calculation for all bands of a multiband raster file.

For the calculation of an image of the statistics of a raster serie, the input file must be a TXT file with the list of raster files in the IMG format to use for the calculation. There must be at least two raster files to perform the calculation and have the same number of rows and columns. The calculation is done pixel by pixel where for each pixel all the valid values of the pixel that are in the same position in the input rasters are selected and with these values the chosen statistical function is applied and the result is written to the raster output file that must be an IMG raster file.

In the option of normalizing a raster, the input file and the output file must be an IMG raster file. This option allows doing this calculation for all bands of a multiband raster file.

In order to calculate the frequencies or areas of the different categories of a categorical raster, the Histo module or the query for attributes of the main module of the MiraMon can be used.


Syntax:

  • EstRas 1 IMGFile FicheroINI Treatment [/N_VAL] [/MIN] [/MAX] [/MITJANA] [/DESV_STD] [/MEDIANA] [/DESV_MEDIANA] [/MODA] [/I_SHAN] [/1Q] [/3Q] [/PERCENTIL] [/MULTIBANDA] [/MEDIANA_EMPAT]
  • EstRas 2 Statistical function IMGList OutputIMGFile [Percentile] [/MEDIANA_EMPAT] [/AJUST]
  • EstRas 3 IMGFile NormIMGFile [/MULTIBANDA] [/PREFIX]

Options:

  • 1: Statistical data of a raster.
  • 2: Image of the statistics of a raster serie.
  • 3: Normalization of a raster.

Parameters:

  • IMGFile (IMG file - Input parameter): Raster file to use for calculating statistics.
  • FicheroINI (INI file - Output parameter): INI file with the result of the calculated statistical data.
  • Treatment (Treatment of the origin data - Input parameter): Indicates the processing of the origin raster data:
    • C: Categorical.
    • N: Quantitative.
    • M: According to metadata.
  • Statistical function (Statistical function - Input parameter): Statistical function to calculate for each pixel of a raster serie:
    • 1: Minimum.
    • 2: Maximum.
    • 3: Mean.
    • 4: Standard deviation.
    • 5: Median.
    • 6: Mode.
    • 7: Shannon Index.
    • 8: Mean absolute deviation from the median.
    • 10: First quartile.
    • 12: Third quartile.
    • 14: Percentile.
    • 15: Regression function.
  • IMGList (IMG list - Input parameter): TXT file with the list of files to use to calculate the image of the chosen statistical function.
  • OutputIMGFile (IMG file - Output parameter): IMG file with the result of the calculated statistical data.
  • Percentile (Percentile - Input parameter): In the case of choosing the Percentile statistical function, indicates which percentile is calculated.
  • NormIMGFile (IMG file - Output parameter): IMG file with the result of the normalization of the input image.

Modifiers:

    /N_VAL (Number of values) To calculate the number of pixels of the input raster (without counting the pixels with NoData value if they exist). (Input parameter)
  • /MIN (Minimum value) To calculate the minimum value of the origin raster. (Input parameter)
  • /MAX (Maximum value) To calculate the maximum value of the origin raster. (Input parameter)
  • /MITJANA (Mean) To calculate the mean of the origin raster. (Input parameter)
  • /DESV_STD (Standard deviation) To calculate the standard deviation of the origin raster. (Input parameter)
  • /MEDIANA (Median) To calculate the median of the origin raster. (Input parameter)
  • /DESV_MEDIANA (Mean absolute deviation from the median) To calculate the mean of the absolute deviation from the median of the origin raster. (Input parameter)
  • /MODA (Mode) To calculate the origin raster mode. (Input parameter)
  • /I_SHAN (Shannon Index) To calculate the Shannon index of the origin raster. (Input parameter)
  • /1Q (First quartile) To calculate the first quartile of the origin raster. (Input parameter)
  • /3Q (Third quartile) To calculate the third quartile of the origin raster. (Input parameter)
  • /PERCENTIL= (Percentile) To calculate the percentile chosen by the user of the origin raster. (Input parameter)
  • /MEDIANA_EMPAT= (Decision for the median) If the calculation of the median has been requested, indicate the type of tiebreaker to be used for its calculation, in case of having an even number of values. The criterion will also be applied when the mean of the absolutes deviations with respect to the median must be calculated (since it requires calculating the median), or some quartile or percentile (in which tie situations can occur). The calculation options are:
    • 1: to choose alternated value.
    • 2: to choose upper value.
    • 3: to choose lower value.
    • 4: to choose average of the central values.
    (Input parameter)
  • /AJUST= (Type of adjustment for the regression function) In case it has been indicated to calculate the regression function, it indicates the type of adjustment to be made:
    • L: Linear.
    • Q: Quadratic.
    (Input parameter)
  • /MULTIBANDA (Multiband) Optional parameter to use all the bands of the input file. (Input parameter)
  • /PREFIX= (Prefix) Prefix of the output files. (Input parameter)
