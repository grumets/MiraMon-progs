• EstRas: Estadísticas de un ráster o de una serie de rásters

Este módulo calcula datos estadísticos de imágenes ráster en el que se puede elegir entre tres opciones: El cálculo de datos estadísticos de un solo ráster (monobanda o multibanda), el cálculo de una imagen con el resultado de la función estadística escogida partir de una serie de rásters y la normalización de un ráster (monobanda o multibanda).

En la opción de cálculo de datos estadísticos de un solo ráster, el fichero de entrada debe ser un fichero ráster IMG y hay que seleccionar al menos una de las funciones estadísticas disponibles (dependiendo del tratamiento de los datos que se seleccione). El fichero de salida debe ser un fichero INI en el cual se escribirá el resultado de los diferentes cálculos estadísticos elegidos. Esta opción permite hacer este cálculo para todas las bandas de un fichero ráster multibanda.

En la opción de cálculo de una imagen de las estadísticas de una serie de rásters, el fichero de entrada debe ser un fichero TXT con la lista de ficheros rásters en formato IMG que se quiere utilizar para el cálculo. Debe incluir al menos dos ficheros rásters para poder realizar el cálculo y deben tener el mismo número de filas y columnas. El cálculo se hace píxel a píxel donde para cada píxel se escoge todos los valores válidos del píxel que está en la misma posición en los rásters de entrada y con estos valores se aplica la función estadística elegida y el resultado se escribe en el fichero ráster de salida que debe ser un fichero ráster IMG.

En la opción de la normalización de un ráster, el fichero de entrada y el fichero de salida deben ser un fichero ráster IMG. Esta opción permite hacer este cálculo para todas las bandas de un fichero ráster multibanda.

Si se desea calcular las frecuencias o las áreas de las diferentes categorías de un ráster categórico, se puede emplear el módulo Histo o bien la consulta por atributos del módulo principal de MiraMon.


Sintaxis:

  • EstRas 1 FicheroIMG FicheroINI Tratamiento [/N_VAL] [/MIN] [/MAX] [/MITJANA] [/DESV_STD] [/MEDIANA] [/DESV_MEDIANA] [/MODA] [/I_SHAN] [/1Q] [/3Q] [/PERCENTIL] [/MULTIBANDA] [/MEDIANA_EMPAT]
  • EstRas 2 FunciónEstadística ListaIMG FicheroIMGSalida [Percentil] [/MEDIANA_EMPAT] [/AJUST]
  • EstRas 3 FicheroIMG FicheroIMGNorm [/MULTIBANDA] [/PREFIX]

Opciones:

  • 1: Datos estadísticos de un ráster.
  • 2: Imagen de las estadísticas de una serie de rásters.
  • 3: Normalización de un ráster.

Parámetros:

  • FicheroIMG (Fichero IMG - Parámetro de entrada): Fichero ráster a usar para el cálculo de estadísticas.
  • FicheroINI (Fichero INI - Parámetro de salida): Fichero INI con el resultado de los datos estadísticos calculados.
  • Tratamiento (Tratamiento de los datos origen - Parámetro de entrada): Indica el tratamiento de los datos del ráster origen:
    • C: Categórico.
    • N: Cuantitativo.
    • M: Según metadatos.
  • FunciónEstadística (Función estadística - Parámetro de entrada): Función estadística a calcular para cada píxel de una serie de rásters:
    • 1: Mínimo.
    • 2: Máximo.
    • 3: Media.
    • 4: Desviación estándar.
    • 5: Mediana.
    • 6: Moda.
    • 7: Índice de Shannon.
    • 8: Media de las desviaciones absolutas respecto de la mediana.
    • 10: Primer cuartil.
    • 12: Tercer cuartil.
    • 14: Percentil.
    • 15: Recta de regresión.
  • ListaIMG (Lista IMG - Parámetro de entrada): Fichero TXT con la lista de archivos que se quieren usar para el cálculo de la imagen de la función estadística elegida.
  • FicheroIMGSalida (Fichero IMG - Parámetro de salida): Fichero IMG con el resultado de los datos estadísticos calculados.
  • Percentil (Parámetro de entrada): En el caso de elegir la función estadística Percentil, indica qué percentil se quiere calcular.
  • FicheroIMGNorm (Fichero IMG - Parámetro de salida): Fichero IMG con el resultado de la normalización de la imagen de entrada.

Modificadores:

    /N_VAL (Número de valores) Para calcular el número de píxeles del ráster origen (sin contar los píxeles con valor sindatos en caso de que existan). (Parámetro de entrada)
  • /MIN (Mínimo valor) Para calcular el valor mínimo del ráster origen. (Parámetro de entrada)
  • /MAX (Máximo valor) Para calcular el valor máximo del ráster origen. (Parámetro de entrada)
  • /MITJANA (Media) Para calcular la media del ráster origen. (Parámetro de entrada)
  • /DESV_STD (Desviación estándar) Para calcular la desviación estándar del ráster origen. (Parámetro de entrada)
  • /MEDIANA (Mediana) Para calcular la mediana del ráster origen. (Parámetro de entrada)
  • /DESV_MEDIANA (Media de las desviaciones absolutas respecto de la mediana) Para calcular la media de las desviaciones absolutas respecto de la mediana del ráster origen. (Parámetro de entrada)
  • /MODA (Moda) Para calcular la moda del ráster origen. (Parámetro de entrada)
  • /I_SHAN (Índice de Shannon) Para calcular el índice de Shannon del ráster origen. (Parámetro de entrada)
  • /1Q (Primer cuartil) Para calcular el primer cuartil del ráster origen. (Parámetro de entrada)
  • /3Q (Tercer cuartil) Para calcular el tercer cuartil del ráster origen. (Parámetro de entrada)
  • /PERCENTIL= (Percentil) Para calcular el percentil escogido por el usuario del ráster origen. (Parámetro de entrada)
  • /MEDIANA_EMPAT= (Desempate para la mediana) Si se ha solicitado el cálculo de la mediana, indica el tipo de desempate a utilizar para su cálculo, en caso de tener un número par de valores. El criterio también se aplicará cuando debe calcularse la media de las desviaciones absolutas respecto de la mediana (ya que requiere calcular la mediana), o algún cuartil o percentil (en la que se pueden dar situaciones de empate). Las opciones de cálculo son:
    • 1: para elegir valor alternado.
    • 2: para elegir valor superior.
    • 3: para elegir valor inferior.
    • 4: para elegir promedio de los valores centrales.
    (Parámetro de entrada)
  • /AJUST= (Tipo de ajuste para la recta de regresión) En caso de que se haya indicado calcular la Recta de regresión, indica el tipo de ajuste a realizar:
    • L: Lineal.
    • Q: Cuadrática.
    (Parámetro de entrada)
  • /MULTIBANDA (Multibanda) Parámetro opcional por si se quiere utilizar todas las bandas del fichero de entrada. (Parámetro de entrada)
  • /PREFIX= (Prefijo) Prefijo de los ficheros de salida. (Parámetro de entrada)
